# 自动化深度研究 Agent

## 1. 项目背景

深度研究需要围绕主题检索资料、筛选来源、归纳观点并形成结构化结论。该案例用于展示 Agent 如何辅助完成公开资料研究草案。

## 2. 业务问题

研究任务容易出现来源分散、引用缺失和结论跳跃。第一版目标是输出可追溯的研究提纲、来源摘要和结论草案。

## 3. 解决方案

Agent 将研究主题拆分为子问题，检索公开资料，提取关键事实和观点，按主题聚类生成研究草案，并标记证据强弱。

## 4. Agent 设计

- 问题拆解节点：生成研究子问题。
- 检索节点：搜索公开资料。
- 来源筛选节点：优先保留官方文档、论文、报告和权威媒体。
- 摘要节点：提取事实、观点和引用。
- 综合节点：生成结构化结论和待验证问题。

## 5. 工具调用

- Web 搜索：寻找公开来源。
- 页面读取：提取正文和发布时间。
- 摘要生成：归纳来源要点。
- Markdown 输出：生成研究草案。

## 6. 实现流程

1. 输入研究主题和范围。
2. 拆分研究问题。
3. 检索并筛选来源。
4. 摘要和聚类。
5. 生成研究报告草案。
6. 人工复核来源和结论。

## 7. 输出结果

第一版输出研究提纲、来源列表、关键发现、分歧点、结论草案和后续验证清单。当前不声明录屏、部署或真实客户交付。

## 8. 评估方式

- 来源质量：是否优先使用可靠来源。
- 引用完整性：关键结论是否有来源。
- 覆盖度：是否覆盖主要子问题。
- 结论边界：是否区分事实、观点和推断。

## 9. 可扩展方向

- 后续可扩展引用管理和快照保存。
- 后续可扩展多轮研究计划。
- 后续可扩展报告导出和对比阅读。
