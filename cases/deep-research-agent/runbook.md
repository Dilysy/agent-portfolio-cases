# 自动化深度研究 Agent 本地复现步骤

## 环境准备

- 准备 Python 或 Node.js 运行环境。
- 准备可访问公开网页的网络环境。
- 明确研究主题、时间范围和来源偏好。

## 依赖安装

当前仓库尚未固定依赖。后续可根据实现选择安装搜索、网页解析和文档生成相关依赖。

## 配置说明

- 配置搜索工具或浏览器检索方式。
- 配置来源数量上限。
- 如使用模型 API，需要通过环境变量配置密钥。

## 启动方式

当前为案例骨架，尚未提供统一启动命令。后续可扩展为：

```bash
python run.py --case deep-research --topic "企业知识库 Agent"
```

## 示例运行

输入研究主题后生成研究草案。当前可通过 `sample.md` 查看预期记录结构。

## 常见问题

- 搜索结果噪声高：缩小时间范围或限定来源类型。
- 结论缺少引用：回退到来源摘要阶段补证据。
- 来源冲突：保留分歧点，不强行合并为确定结论。
