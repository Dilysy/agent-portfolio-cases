# 自动化深度研究 Agent 示例运行记录

## 示例输入

- 参考材料：`docs/chapter14/第十四章 自动化深度研究智能体.md`
- 研究主题示例：`Datawhale 是一个什么样的组织？`
- 目标输出：TODO 列表、搜索摘要、来源记录和最终 Markdown 报告。

## 执行过程

1. 用户输入研究主题。
2. TODO Planner 将主题拆成多个子任务，例如组织定位、主要项目、社区文化、影响力。
3. 每个子任务生成独立搜索查询。
4. SearchTool 返回标题、URL、摘要等搜索结果。
5. Task Summarizer 提取关键事实和来源引用。
6. NoteTool 保存每个子任务的研究笔记。
7. Report Writer 汇总所有子任务总结，生成结构化报告。

## 工具调用记录

| 步骤 | 工具 | 输入 | 输出 |
| --- | --- | --- | --- |
| 1 | TODO Planner | 研究主题和当前日期 | 3-5 个子任务 |
| 2 | SearchTool | 子任务查询语句 | 搜索结果列表 |
| 3 | Task Summarizer | 子任务和搜索结果 | Markdown 摘要 |
| 4 | NoteTool | 摘要、来源、标签 | 工作区 Markdown 笔记 |
| 5 | Report Writer | 全部子任务摘要 | 最终研究报告 |

## 示例输出

章节中的示例输出形态包括：

- `title`：子任务标题
- `intent`：研究意图
- `query`：搜索查询
- 每个子任务的 Markdown 摘要
- 来源列表
- 最终报告

## 人工复核结论

需要人工检查搜索结果是否可靠、来源是否过旧、总结是否忠于来源、报告是否区分事实和推断。涉及最新事实时，需要重新检索确认。
