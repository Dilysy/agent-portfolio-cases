# 自然语言数据库查询 Agent 本地复现步骤

## 环境准备

- 准备 Python 或 Node.js 运行环境。
- 准备本地 SQLite 样例数据库。
- 不连接真实生产数据库。

## 依赖安装

当前仓库尚未固定依赖。后续可根据实现选择安装数据库连接、SQL 解析和模型调用相关依赖。

## 配置说明

- 配置数据库路径。
- 配置允许访问的表和字段。
- 配置最大返回行数。
- 如使用模型 API，需要通过环境变量配置密钥。

## 启动方式

当前为案例骨架，尚未提供统一启动命令。后续可扩展为：

```bash
python run.py --case database-query --db data/sample.sqlite
```

## 示例运行

输入自然语言问题，生成只读 SQL，执行查询并输出解释。当前可通过 `sample.md` 查看预期记录结构。

## 常见问题

- 字段不存在：先检查 schema 或补充字段映射。
- SQL 不安全：拒绝执行并要求重新生成。
- 结果解释不准确：以查询结果为准，重新生成解释。
