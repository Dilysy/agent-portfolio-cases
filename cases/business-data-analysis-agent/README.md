# 企业经营数据分析 Agent

## 1. 项目背景

经营分析需要从订单、收入、成本、用户或渠道数据中识别趋势和异常。该案例用于展示 Agent 如何围绕结构化数据生成指标解读和分析草案。

## 2. 业务问题

数据表格常包含多个维度和指标，非技术用户需要快速理解变化原因、异常点和下一步分析方向。第一版仅使用样例或模拟数据，不接入真实企业数据。

## 3. 解决方案

Agent 读取 CSV 或表格样例，识别字段含义，计算基础指标，生成趋势分析、异常解释和后续问题建议。关键计算结果需要可复核。

## 4. Agent 设计

- 字段识别节点：识别日期、金额、品类、渠道等字段。
- 指标计算节点：计算收入、订单量、客单价、环比等指标。
- 异常检测节点：识别突增、突降和缺失数据。
- 解读生成节点：输出分析摘要和后续问题。
- 复核节点：检查口径、公式和数据范围。

## 5. 工具调用

- 文件读取：读取 CSV 或表格。
- 数据分析工具：执行聚合、排序、筛选和基础统计。
- 图表生成：后续可扩展趋势图和对比图。
- Markdown 输出：生成分析报告草案。

## 6. 实现流程

1. 上传或指定样例数据。
2. 识别字段和数据范围。
3. 计算核心指标。
4. 检测异常点。
5. 生成分析结论和复核清单。

## 7. 输出结果

第一版输出指标摘要、趋势描述、异常点列表、可能原因和后续分析建议。所有结论基于样例数据，不写成真实经营结果。

## 8. 评估方式

- 公式正确性：抽样检查指标计算。
- 口径一致性：字段含义和计算范围是否清楚。
- 异常识别有效性：异常点是否可由数据支持。
- 可解释性：结论是否能追溯到数据。

## 9. 可扩展方向

- 后续可扩展多文件合并分析。
- 后续可扩展图表生成和仪表盘草案。
- 后续可扩展自然语言追问。
