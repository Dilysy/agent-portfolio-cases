# 智能竞品分析 Agent

## 1. 项目背景

竞品分析通常需要收集官网、文档、新闻、定价页和公开评价等资料，再整理成对比表与结论。该案例用于展示 Agent 如何在公开信息范围内完成资料检索、结构化整理和人工复核辅助。

## 2. 业务问题

手工竞品分析耗时较长，容易遗漏来源，也容易把未经证实的判断写成结论。第一版目标是把公开信息整理为可追溯、可复核的分析草案。

## 3. 解决方案

Agent 接收目标产品和竞品列表，按维度检索公开资料，抽取产品定位、核心功能、价格信息、目标用户和差异点，并生成结构化报告。所有结论都需要保留来源或标记为待验证。

## 4. Agent 设计

- 规划节点：拆分分析维度和检索关键词。
- 检索节点：收集公开网页、文档和新闻资料。
- 抽取节点：提取事实、功能点、价格区间和限制条件。
- 分析节点：生成对比表、机会点和风险点。
- 复核节点：检查是否存在无来源判断或过度推断。

## 5. 工具调用

- Web 搜索：获取公开资料。
- 页面读取：提取网页正文和关键信息。
- 表格生成：整理竞品对比矩阵。
- 文档生成：输出 Markdown 报告草案。

## 6. 实现流程

1. 输入目标产品、竞品名单和分析维度。
2. 生成检索计划。
3. 收集公开来源并记录链接。
4. 抽取事实并去重。
5. 生成对比表和结论草案。
6. 人工复核来源和结论边界。

## 7. 输出结果

第一版输出 Markdown 报告草案，包括竞品概览、功能对比、定价观察、差异点、风险点和后续验证清单。当前不声明已经完成真实客户交付。

## 8. 评估方式

- 来源覆盖率：关键结论是否有来源。
- 事实一致性：同一事实在多个来源之间是否冲突。
- 结构完整性：是否覆盖预设分析维度。
- 人工复核：标记待验证内容和无法确认的信息。

## 9. 可扩展方向

- 后续可扩展多轮追问和分析维度配置。
- 后续可扩展网页快照和引用管理。
- 后续可扩展报告导出为 PDF 或 PPT。
