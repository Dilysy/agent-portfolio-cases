# 智能竞品分析 Agent 示例运行记录

## 示例输入

- 目标产品：某开源知识库工具
- 竞品范围：3 个同类开源或 SaaS 工具
- 分析维度：产品定位、核心功能、定价、部署方式、适用团队

## 执行过程

1. 拆分检索问题和对比维度。
2. 根据产品名称生成检索关键词。
3. 读取公开页面并抽取事实。
4. 整理竞品对比表。
5. 生成结论草案和待复核项。

## 工具调用记录

| 步骤 | 工具 | 输入 | 输出 |
| --- | --- | --- | --- |
| 1 | 搜索工具 | 产品名 + 定价/文档/部署 | 候选来源列表 |
| 2 | 页面读取工具 | 公开 URL | 页面摘要和事实片段 |
| 3 | Markdown 生成 | 抽取结果 | 分析报告草案 |

## 示例输出

输出包含竞品对比表、差异点摘要、风险点和待验证清单。当前为样例结构，尚未绑定固定公开数据集。

## 人工复核结论

需要人工确认价格、授权协议和部署限制等信息是否与来源一致。无法确认的信息必须标记为待验证。

## 当前不足

- 尚未形成稳定测试数据集。
- 来源可信度排序规则还需要细化。
- 结论生成仍依赖人工复核。

## 可改进方向

- 增加来源权重评分。
- 增加事实冲突检测。
- 增加报告导出模板。
