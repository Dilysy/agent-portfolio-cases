# 智能股票分析助手 Agent 示例运行记录

## 1. 示例输入

本案例使用以下三个前端演示输入：

```text
查询贵州茅台 600519 的实时行情
分析贵州茅台 600519 的技术指标
分析贵州茅台 600519 的近期行情和主要风险
```

## 2. 执行过程

1. 打开本地 Gradio 前端。
2. 选择快速分析模式。
3. 输入股票实时行情查询问题。
4. 页面展示工具调用过程和实时行情结果。
5. 输入技术指标分析问题。
6. 页面展示 MA、MACD、RSI、布林带和关键价位等结果。
7. 输入近期行情和主要风险问题。
8. 页面展示行情、技术指标和风险因素归纳。
9. 录屏素材经抽帧检查后生成中文字幕演示视频。

## 3. 工具调用记录

| 示例输入 | 工具调用 | 输出内容 | 当前状态 |
| --- | --- | --- | --- |
| 查询贵州茅台 600519 的实时行情 | 实时行情工具 | 最新价格、涨跌幅、成交量、基础指标 | 已验证 |
| 分析贵州茅台 600519 的技术指标 | 技术指标工具 | MA、MACD、RSI、布林带、关键价位 | 已验证 |
| 分析贵州茅台 600519 的近期行情和主要风险 | 实时行情工具、技术指标工具 | 近期行情摘要、技术指标摘要、主要风险因素 | 已验证 |

## 4. 示例输出

输出样例包括：

- 实时行情：展示公开行情字段和基础指标。
- 基础指标：展示价格、涨跌幅、成交量等信息。
- 技术指标分析：展示均线、MACD、RSI、布林带和关键价位。
- 近期行情分析：基于公开行情和技术指标做结构化整理。
- 主要风险提示：列出需要人工复核的风险因素。
- 边界说明：仅用于公开信息分析流程演示，不构成投资建议。

## 5. 人工复核结论

当前前端演示路径已验证可用，适合展示：

1. Gradio 前端交互。
2. 自然语言股票查询输入。
3. 工具调用过程。

## 6. 边界说明

1. 当前视频重点展示实时行情和技术指标，财务数据与新闻信息只作为后续可扩展能力。
2. 页面局部仍保留内部应用标题，但正式片头和字幕已统一使用“智能股票分析助手 Agent”。
3. 当前报告为展示版整理，不构成正式金融服务或交易决策依据。
