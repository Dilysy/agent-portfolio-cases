# 智能股票分析助手 Agent

当前状态：已完成。

本案例用于展示一个面向公开股票信息分析流程的 Agent 应用：用户通过 Gradio 前端输入股票相关问题，系统调用公开行情与技术指标工具，生成结构化分析结果，并保留人工复核和风险边界说明。

> 边界说明：本案例仅用于公开信息分析流程演示，不构成投资建议。

## 1. 项目背景

股票相关公开信息分散在行情、历史走势、技术指标、新闻和财务数据等多个来源中。人工整理这些信息时，常见问题包括查询步骤重复、指标口径分散、结果难以结构化复盘。

本案例将公开数据查询、技术指标计算、前端交互和结构化输出封装为一个本地化 Agent 演示流程，用于展示工具调用、前端交互和分析结果组织能力。

## 2. 业务问题

1. 普通用户难以快速把公开行情和技术指标组合成清晰结果。
2. 多个数据源和指标口径需要统一展示。
3. 分析过程缺少可见的工具调用记录。
4. 股票分析类输出容易被误解为交易决策，需要明确边界。

## 3. 解决方案

智能股票分析助手 Agent 提供 Gradio 前端，支持自然语言输入股票查询问题，并通过工具调用完成：

- 实时行情查询。
- 基础指标展示。
- 技术指标分析。
- 近期行情和主要风险因素归纳。
- 结构化输出和边界提示。

当前演示已完成真实 LLM 调用验证、Gradio 前端验证和中文字幕演示视频生成。

## 4. Agent 设计

| 模块 | 说明 |
| --- | --- |
| 前端交互 | Gradio Chatbot，用于输入问题、展示工具调用过程和分析结果。 |
| 快速分析 | ReAct 风格的工具调用流程，用于展示公开行情和技术指标结果。 |
| 深度分析 | 可扩展为 Plan-and-Solve 流程，用于更完整的多步骤分析。 |
| 批判分析 | 可扩展为 Reflection 流程，用于对输出做复核和修正。 |
| 记忆能力 | 支持关注列表和历史记录等本地持久化能力，录屏中只展示必要前端路径。 |
| 知识库能力 | 支持本地知识检索，用于后续扩展指标解释和风险复核。 |

## 5. 工具调用

| 工具能力 | 输入 | 输出 | 展示状态 |
| --- | --- | --- | --- |
| 实时行情查询 | 股票代码或名称 | 最新价格、涨跌幅、成交量、基础指标 | 已验证 |
| 历史行情数据 | 股票代码、周期、天数 | 日线 / 周线等公开 K 线数据 | 已梳理，后续可扩展展示 |
| 技术指标计算 | 股票代码、周期、天数 | MA、MACD、RSI、布林带、关键价位 | 已验证 |
| 财务数据查询 | 股票代码 | 营收、利润率、负债率等公开指标 | 已梳理，后续可扩展展示 |
| 新闻信息查询 | 股票代码 | 相关新闻摘要 | 已梳理，后续可扩展展示 |

## 6. 实现流程

1. 启动本地 Gradio 前端。
2. 用户输入股票分析问题。
3. Agent 识别任务类型。
4. 调用公开行情或技术指标工具。
5. 将工具返回结果整理为结构化说明。
6. 在页面中展示分析结果和边界提示。
7. 通过 ffmpeg 生成中文字幕演示视频。
