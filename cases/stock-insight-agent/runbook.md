# 智能股票分析助手 Agent 本地化运行记录

## 1. 工程入口

本案例对应一个本地 Gradio 股票分析助手工程。公开演示只记录本地验证过程、运行验证和展示素材，不记录任何私密配置内容。

常用入口：

```bash
python app.py
```

前端访问：

```text
http://127.0.0.1:7861
```

## 2. 项目定位

智能股票分析助手 Agent 用于公开股票信息分析流程演示，覆盖自然语言输入、公开行情查询、技术指标计算、结构化输出和风险边界说明。

本案例不是交易建议系统、交易系统或真实金融服务。

## 3. 环境准备

建议环境：

- Python 3.10+
- 本地虚拟环境
- 可访问公开行情数据源
- 已完成本地 LLM 配置
- 浏览器访问 Gradio 前端

本 runbook 不记录私密配置、密钥、接口地址或模型配置。

## 4. 依赖安装

示例流程：

```bash
cd 原工程目录
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

如果本地 Python 版本较旧，需使用 Python 3.10 以上环境重新创建虚拟环境。

## 5. 本地配置说明

需要用户在原工程中手动配置本地私密配置文件。本仓库不记录配置文件内容，不提交密钥，不展示接口地址或模型配置。

录屏前需要确认：

1. 浏览器页面不展示私密配置。
2. 终端窗口不进入录屏。
3. 输出内容不包含账号、密钥、接口地址或私密路径。

## 8. 常见问题

### 前端长时间等待

复杂综合问题可能导致多轮工具调用时间较长。当前演示采用快速分析路径，确保录屏输入稳定展示公开行情、技术指标和风险因素归纳。

### 数据源返回慢

公开数据接口可能受网络波动影响。录屏前建议先运行一次示例问题，确认返回速度和展示效果。

### 页面局部英文标题

视频页面局部保留内部应用标题。正式片头和中文字幕已统一使用“智能股票分析助手 Agent”，对外文档也使用中文名称。
