# AutoFlow 流程图生成 Agent

## 1. 项目背景

业务流程、审批流程和系统交互流程常以自然语言描述，整理为流程图需要反复确认节点、分支和边界。该案例用于展示 Agent 如何把文本流程转换为可编辑流程图草案。

## 2. 业务问题

流程描述容易混杂角色、条件、动作和异常分支，直接绘图成本较高。第一版目标是生成可复核的 Mermaid 流程图和节点说明。

## 3. 解决方案

Agent 接收流程文本，抽取角色、动作、条件和结束状态，生成 Mermaid 流程图，并列出不确定节点供人工确认。

## 4. Agent 设计

- 解析节点：识别角色、动作、判断条件和顺序关系。
- 结构化节点：将流程转换为节点和边。
- 生成节点：输出 Mermaid 图和说明。
- 校验节点：检查孤立节点、循环和缺失结束状态。
- 复核节点：列出需要人工确认的问题。

## 5. 工具调用

- 文本解析：抽取流程要素。
- Mermaid 生成：输出流程图代码。
- Markdown 输出：生成说明文档。
- 后续可扩展图像渲染工具。

## 6. 实现流程

1. 输入自然语言流程描述。
2. 抽取角色、动作和判断条件。
3. 生成节点和连线。
4. 输出 Mermaid 流程图。
5. 生成复核问题清单。

## 7. 输出结果

第一版输出 Mermaid 流程图、节点解释、假设说明和待确认问题。当前不声明已完成部署或交付。

## 8. 评估方式

- 结构完整性：是否覆盖全部关键步骤。
- 逻辑一致性：分支条件和结束状态是否清楚。
- 可编辑性：Mermaid 是否能被后续工具渲染。
- 人工复核：业务人员能否基于问题清单确认流程。

## 9. 可扩展方向

- 后续可扩展 BPMN 导出。
- 后续可扩展流程差异对比。
- 后续可扩展交互式节点编辑。
