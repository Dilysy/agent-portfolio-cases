# 工具调用设计

## 工具类型

- 搜索工具：用于公开资料发现。
- 页面读取工具：用于正文提取和来源摘要。
- 文件读取工具：用于 CSV、Markdown 和配置文件读取。
- 数据分析工具：用于聚合、排序、筛选和基础统计。
- 数据库工具：用于 schema 读取和只读 SQL 查询。
- 生成工具：用于 Markdown、Mermaid、报告草案输出。

## 调用原则

1. 先明确输入和输出，再选择工具。
2. 对外部来源保留链接、时间和摘要。
3. 对数据库操作默认只读。
4. 对不确定结果保留人工复核项。
5. 工具失败时记录失败原因和替代演示方式。

## 记录格式

每个案例的 `sample.md` 都需要记录工具调用，包括步骤、工具、输入和输出。当前阶段先记录预期结构，待案例跑通后补充真实运行日志。

## 风险控制

- 不把搜索结果直接写成事实结论。
- 不执行写入、删除或更新数据库的操作。
- 不把模拟数据分析写成真实经营结果。
- 不把未生成的截图、录屏或部署写成已完成。
