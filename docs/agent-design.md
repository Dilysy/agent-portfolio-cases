# Agent 设计说明

## 设计目标

本仓库中的 Agent 案例重点展示企业知识工作流中的任务拆解、工具调用、结果生成和人工复核。案例均为作品集演示，不写成真实客户交付。

## 通用架构

1. 输入理解：解析用户目标、约束和输出格式。
2. 任务规划：拆分为检索、分析、生成和复核步骤。
3. 工具执行：调用搜索、文件、数据库或图表工具。
4. 中间结果整理：保留来源、SQL、计算过程或流程节点。
5. 输出生成：生成 Markdown 报告、表格、流程图或查询解释。
6. 人工复核：标记不确定内容、阻塞点和可改进方向。

## 设计原则

- 事实和推断分开表达。
- 规划能力写成后续可扩展，不写成已完成。
- 关键输出保留复核线索。
- 不接入真实生产数据或客户环境。

## 案例差异

- 竞品分析 Agent 偏公开资料检索和结构化对比。
- 经营数据分析 Agent 偏数据聚合、指标解释和异常识别。
- AutoFlow Agent 偏文本结构化和图生成。
- 深度研究 Agent 偏来源筛选、观点归纳和引用管理。
- 数据库查询 Agent 偏 schema 理解、SQL 生成和只读安全校验。
