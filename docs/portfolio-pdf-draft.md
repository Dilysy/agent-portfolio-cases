# PDF 作品集文案草案

## 封面

企业知识工作流 Agent 作品集

## 简介

本作品集整理 5 个 Agent 案例，覆盖竞品分析、经营数据分析、流程图生成、深度研究和自然语言数据库查询。案例围绕公开资料、本地样例数据和企业知识工作流场景进行工程化封装与应用验证，不写成真实客户交付。

## 案例目录

1. 智能竞品分析 Agent
2. 企业经营数据分析 Agent
3. AutoFlow 流程图生成 Agent
4. 自动化深度研究 Agent
5. 自然语言数据库查询 Agent

## 能力摘要

- Agent 任务拆解和规划。
- 工具调用链路设计。
- 结构化输出和 Markdown 报告生成。
- 数据分析、Text-to-SQL 和流程图生成。
- 人工复核和评估记录。

## 当前状态

当前为可提交初版骨架。截图、录屏、部署和完整报告样例暂未纳入正式展示范围，后续会在案例跑通后补充。

## 使用边界

本作品集不包含真实客户交付经历，不包含 SRE 运维类案例，不使用真实企业敏感数据。
