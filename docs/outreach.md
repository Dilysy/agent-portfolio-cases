# 求职与接单沟通草案

## 定位表达

这个作品集展示的是我围绕企业知识工作流 Agent 做场景化构建、能力封装和工程化整理的能力，重点包括任务拆解、工具调用、输出结构、评估方式和本地化运行验证文档。

## 可沟通能力

- 能把开放业务问题拆成可执行 Agent 流程。
- 能设计工具调用链路和输出格式。
- 能围绕公开资料、样例数据和本地数据库完成演示。
- 能记录限制、阻塞点和人工复核方式。

## 不应夸大的内容

- 不说已经服务真实客户。
- 不说已经完成生产部署。
- 不说可以完全替代人工分析。
- 不使用虚构企业名称或真实交付结果。

## 后续可补充

- 每个案例的截图和报告样例。
- 简历中的项目描述。
- 面试讲解提纲。
- 轻量接单服务边界说明。
