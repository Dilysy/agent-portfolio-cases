# 评估方式

## 评估目标

评估重点不是证明 Agent 完全自动化，而是说明输出是否可复核、是否忠于数据和来源、是否能稳定完成一个清晰边界内的任务。

## 通用评估维度

- 准确性：事实、计算、SQL 或流程结构是否正确。
- 完整性：是否覆盖预设输入和输出结构。
- 可追溯性：关键结论是否能回到来源、数据或查询结果。
- 安全性：是否避免危险数据库操作和敏感数据使用。
- 可解释性：是否说明假设、限制和待验证问题。

## 人工复核

第一版以人工复核为主。每个案例都需要记录复核结论、当前不足和可改进方向，不把未验证能力写成稳定能力。

## 后续可扩展

- 构建固定测试集。
- 增加自动化结构检查。
- 增加 SQL、Mermaid 或数据计算的单元测试。
- 增加引用链接校验。
