# AutoFlow 演示视频中文配音稿

这是 AutoFlow 流程图生成 Agent 的本地复现演示。

项目已完成 LLM 接入，当前演示按 Pro/moonshotai/Kimi-K2.6 模型规划，并对灵感模式、标准模式、计划模式和 Mermaid 代码模式进行了验证。

AutoFlow 的核心目标，是把自然语言中的流程描述，转换为可检查、可渲染、可导出的 Mermaid 流程图。

在页面左侧，可以选择不同生成模式并输入流程描述。右侧会展示流程图预览，便于快速确认结构是否正确。

首先看灵感模式。用户只需要输入一个较粗略的想法，例如销售跟进流程，系统会补全阶段，并生成可视化流程。

接着是标准模式。对于包含条件分支的业务描述，系统会识别需求是否明确、客户是否通过等判断点，并生成带回退路径的流程图。

计划模式用于线性计划转换。本次复现已经修复单节点伪成功问题，系统会把计划拆解为多个步骤，而不是把整段输入放进一个节点。

Mermaid 代码模式用于直接编辑流程图代码。它适合作为人工修订、校验和兜底演示入口。

生成结果可以继续导出，沉淀为文档、报告或演示素材。

这个案例基于开源项目复现和改造，重点验证了 LLM 接入、四模式流程生成、Mermaid 结构校验和本地演示能力。

- 素材导入顺序：按照 `clip-01` 到 `clip-06` 顺序排入主轨，截图作为片头、补帧和段落停顿使用。
- 片头文字：`AutoFlow 流程图生成 Agent`；副标题：`本地复现 · LLM 接入 · 四模式验证`。

- 配音节奏：语气专业、简洁、平稳；每句之间保留短暂停顿，功能切换处停顿更明显。
- 转场要求：页面内操作保持连续；模式切换使用短淡入淡出。
- 导出规格：1920x1080，MP4，H.264。
- 成片文件名：`autoflow-agent-demo.mp4`。
