# AutoFlow 演示视频中文配音稿

本视频展示 AutoFlow 流程图生成 Agent 的本地化运行验证效果。

案例重点验证自然语言输入到流程图预览的完整链路。

系统已接入大模型，可以把流程描述转换为 Mermaid 结构，并在页面右侧实时渲染。

在灵感模式下，用户输入一个初步想法，系统会补全流程阶段，生成可视化结构。

在标准模式下，用户输入较清晰的业务流程描述，系统生成对应的 Mermaid 流程图，并展示判断节点和流转关系。

在计划模式下，系统会把售前项目计划拆解为多个推进步骤，避免把整段文本塞进单个节点。

在 Mermaid 代码模式下，用户可以直接编辑流程图代码，并在右侧实时查看渲染结果。

生成后的结果可以继续修改，也可以导出为 `.mmd` 或 SVG 文件，便于沉淀到文档和演示材料中。

这个案例验证了本地化运行验证、LLM 接入、四模式流程生成、实时预览与结果导出的基本能力。
