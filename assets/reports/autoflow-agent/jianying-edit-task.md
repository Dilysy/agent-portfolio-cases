# AutoFlow jianying-editor-skill 剪辑任务

## 任务目标

基于 AutoFlow 原始录屏和截图，制作一版 75-90 秒的正式产品演示视频，用于 Agent 案例集、GitHub、PDF 和客户展示。

本视频定位为 AutoFlow 工程化演示，只展示功能路径和验证结果，不包装成真实客户交付项目。

- 输出路径：`assets/demos/autoflow-agent/autoflow-agent-demo.mp4`
- 视频规格：1920x1080，MP4，H.264
- 总时长：75-90 秒

## 剪辑原则

- 从 `autoflow-raw-demo.mov` 中剪出可用片段，使用 4 张模式截图作为标题页、结果停留、转场补帧或结尾画面。
- 删除原始视频中的无关操作、等待时间、鼠标乱动、重复画面和无效停顿。
- 删除所有报错画面、终端画面、Codex 画面、桌面隐私、私密凭证、账号信息、微信、邮箱等内容。
- 操作过程可以适当加速，建议 1.25x 到 1.5x。
- 关键结果画面不要加速，保留 3-5 秒停留。
- 添加中文配音和同步中文字幕。
- 字幕置于底部居中，白色字体，轻微黑色描边，不遮挡输入框、流程图和导出按钮。
- 转场使用简单淡入淡出，不使用夸张特效。
- 背景音乐可选；如使用，音量必须低于配音，不干扰讲解。
- 不开始额外录屏，不移动、覆盖或删除任何原始素材。

## 完整配音稿

本案例展示 AutoFlow 流程图生成 Agent 的本地化运行验证效果。

系统已接入大模型，支持将自然语言描述转化为可视化流程图。

在灵感模式下，用户输入一个初步想法，系统可以生成可视化流程结构。

在标准模式下，用户输入清晰的业务流程描述，系统生成对应的 Mermaid 流程图。

在计划模式下，系统可以根据售前项目计划，整理出项目推进流程。

在 Mermaid 代码模式下，用户可以直接编辑代码，并在右侧实时预览流程图。

生成结果支持继续修改，也可以导出为 .mmd 或 SVG 文件。

该案例验证了从自然语言输入、模型生成、流程图预览到结果导出的完整链路。

## 字幕与音频要求

- 字幕文本与配音稿同步，尽量按句拆分，避免单条字幕过长。
- 字幕底部居中，白色无衬线字体，轻微黑色描边或弱阴影。
- 字幕不得遮挡输入框、流程图主体、模式切换按钮和导出按钮。
- 配音语气专业、自然、克制，不使用广告式夸张表达。
- 配音音量保持稳定；如添加背景音乐，背景音乐需明显低于配音。
