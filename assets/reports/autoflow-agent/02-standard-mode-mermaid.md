# 标准模式 Mermaid

## 测试输入

```text
客户提交需求后，销售进行需求确认。需求明确则进入方案编写，需求不明确则返回客户补充信息。方案完成后提交客户评审，客户通过后进入合同流程，未通过则返回修改。
```

```mermaid
flowchart TD
    Start([开始])
    A[客户提交需求]
    B[销售进行需求确认]
    C{需求是否明确?}
    D[进入方案编写阶段]
    E[返回客户补充信息]
    F[方案完成]
    G[提交客户评审]
    H{客户是否通过?}
    I[进入合同流程]
    J[返回修改]
    End([结束])
    Start --> A
    A --> B
    B --> C
    C -- 是 --> D
    C -- 否 --> E
    E --> B
    D --> F
    F --> G
    G --> H
    H -- 是 --> I
    H -- 否 --> J
    J --> D
    I --> End
```
