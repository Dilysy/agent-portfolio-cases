自然语言问题

业务查询输入

查询 2025 年各地区销售额排名前 5 的地区，并返回销售额和订单数。

当前页面使用模拟销售业务 Schema，不连接真实企业数据库，不代表真实客户交付结果。
Schema 示例

核心表结构

表名 用途 关键字段
orders 订单事实表 order_date, region, customer_type, product_category, sales_amount, order_count, gross_margin
customers 客户维表 customer_id, customer_type, region, industry
products 商品维表 product_id, product_name, product_category, price
生成 SQL

Oracle 兼容 SQL 示例

SELECT
  region,
  SUM(sales_amount) AS total_sales,
  SUM(order_count) AS total_orders
FROM orders
WHERE order_date >= DATE '2025-01-01'
  AND order_date < DATE '2026-01-01'
GROUP BY region
ORDER BY total_sales DESC
FETCH FIRST 5 ROWS ONLY;

结果解释

业务含义

华东地区销售额和订单数均最高，说明该区域市场基础更强；华南具备继续增长空间；西南销售规模相对较低，后续可结合客户类型和商品类别进一步分析。

安全控制

企业落地必须补充的控制项

  • 使用只读数据库账号，禁止使用管理员账号演示或上线。
  • 建立 SQL 白名单，禁止 DROP、DELETE、UPDATE、INSERT 等危险语句。
  • 增加查询行数限制、查询超时限制和 SQL 执行前确认机制。
  • 对敏感字段脱敏，建立表级和字段级权限控制。
  • 记录查询审计日志，包括用户、问题、SQL、时间和结果行数。
