## 6. 人工复核说明

正式使用时需要复核：

1. 日期范围是否符合业务统计口径。
2. 销售额是否含税、是否包含退款或折扣。
3. 订单数是否为订单行数或订单主表数量。
4. 毛利率是否按订单维度、商品维度或财务核算口径计算。
5. 查询是否触及敏感字段或超出用户权限。
