# 科研工作流样例：面向企业知识库问答的 RAG 评估方法研究

本文件为科研创新助手 Agent 的流程演示样例，正式使用时需要接入论文搜索、PDF 解析和人工复核流程。当前内容不代表真实科研结论。

## 1. 研究目标

围绕企业知识库问答场景，梳理 RAG 系统评估方法，重点关注：

- 检索阶段如何评估召回率、相关性、覆盖度和证据质量。
- 生成阶段如何评估答案准确性、忠实性、可引用性和可读性。
- 端到端问答如何结合自动指标、人工复核和业务验收。
- 企业内部知识库场景中，如何处理权限、时效性、来源追溯和低置信度回答。

## 4. PDF 分析摘要样例

Miner Agent 预期输出结构：

```text
论文主题：RAG 系统评估
研究问题：如何评估检索增强生成系统在开放问答或企业知识库问答中的效果。
方法概述：将评估拆为检索、生成和端到端问答三个层级，分别设计自动指标和人工评审标准。
关键指标：Context Precision、Context Recall、Faithfulness、Answer Relevance、Citation Accuracy。
局限性：自动指标可能无法覆盖企业知识库权限、文档时效性和业务上下文差异。
```

人工复核要求：

- 核对指标名称是否来自真实论文或工具文档。
- 核对指标解释是否与原文一致。
- 核对是否存在模型补全或过度推断。

## 5. 创新点提取样例

| 维度 | 样例结论 | 复核要求 |
| --- | --- | --- |
| 评估拆解 | 将 RAG 评估拆为检索、生成、引用、人工复核四层 | 需确认是否符合候选论文原文 |
| 企业适配 | 增加权限、时效性、来源追溯和低置信度处理 | 这是面向企业场景的二次整理，需要人工标注为方案建议 |

| 报告输出 | 结构化输出指标表、问题样例、引用依据和改进建议 | 可作为后续演示报告结构 |

## 6. 写作辅助建议样例

Coach Agent 可对综述草稿提出如下建议：

1. 先说明企业知识库问答和开放域问答的差异，例如权限控制、内部术语、文档版本和答案责任边界。
2. 将评估指标分为检索质量、生成质量、引用可信度和业务可用性四组，避免指标混杂。
3. 对每个指标增加“自动计算方式”“人工复核方式”“适用边界”三列。
4. 在报告结尾明确写出当前结论需要人工复核，不将自动评估结果作为最终验收。

## 9. 人工复核说明

本样例仅用于演示科研创新助手 Agent 的工作流。正式使用前必须完成：

1. 使用真实 ArXiv / Crossref / PDF 输入生成候选材料。
2. 对论文题名、作者、年份、链接和 DOI 做人工复核。
3. 对 LLM 生成的摘要、创新点、局限性和结论逐条核对原文。
4. 对引用格式进行人工检查。
5. 在作品集展示中明确标注为本地复现和流程演示，不写成真实科研结论。
