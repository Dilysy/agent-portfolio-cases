四大 Agent

Hunter

论文搜索与监控

根据关键词检索 ArXiv，后续可扩展 IEEE 等来源；输出候选论文、摘要、链接和 PDF 地址。

Miner

PDF 分析与挖掘

解析 PDF 或 ArXiv 摘要，生成摘要、创新点、对比分析和综合分析；完整结果需 LLM。

Coach

写作辅助与润色

对综述草稿做学术润色、解释、扩写和表达建议；用于报告整理，不替代人工判断。

Validator

引用校验与格式化

识别 ArXiv ID 或 DOI，生成 BibTeX、APA、IEEE、MLA 引用，并标注未验证内容。

综述报告输出样例

面向企业知识库问答的 RAG 评估方法研究
  • 研究背景：企业知识库问答需要同时评估检索证据、答案忠实性和业务可用性。
  • 指标体系：检索召回、上下文相关性、答案忠实性、引用准确性、人工复核通过率。
  • 工具链：Hunter 搜索候选论文，Miner 分析方法，Validator 校验引用，Coach 整理报告。
  • 复核要求：所有论文题名、作者、年份、DOI、结论和引用都需要人工确认。
