```text
000s-020s：首页和 Agent 模块总览
030s-040s：Hunter 搜索结果
055s-060s：Miner 分析输入
110s-125s：Miner 结构化分析结果
135s-140s：Coach 输入和任务选择
220s-225s：Coach 写作建议结果
235s-245s：Validator 引用校验和 BibTeX 结果
```

建议删除或强压缩的低信息片段：

```text
025s：Hunter 短等待
060s-105s：Miner 长等待
145s-215s：Coach 长等待
235s：Validator 短等待
```

建议加速方式：

```text
等待片段统一 3x-6x。
信息增量极低的等待画面可直接删除，只保留点击前和结果出现后。
```
