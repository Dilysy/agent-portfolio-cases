# 科研创新助手 Agent 剪辑计划

## 1. 剪辑目标

- 成片时长：控制在 70-90 秒，本计划预计约 82 秒。
- 输出格式：MP4 / H.264 / 1920x1080。
- 字幕：必须烧录中文字幕硬字幕。
- 音频：不做配音，成片静音。
- 内容：保留真实 Web/API 页面演示过程，不展示敏感配置、终端、报错堆栈或无关桌面内容。
- 叙事：按科研辅助流程展示 Hunter、Miner、Coach、Validator 四类能力。
- 边界：结尾明确说明结果用于科研辅助演示，正式使用仍需人工复核。

## 8. 等待片段处理策略

1. 等待大模型返回的画面不完整保留。
2. 加载过程统一做 3x-6x 加速，本计划对主要等待段使用 5x 或 6x。
3. 无信息增量的等待画面直接裁掉，尤其是 Coach 长等待中段。
4. 结果出现后的画面正常保留，保证观众能看清结构化分析、写作建议和 BibTeX。
5. 目标是让视频体现能力流程，而不是突出调用耗时。

## 10. 敏感信息与展示边界

抽帧检查未发现鉴权值、模型服务配置、敏感配置文件、Codex 对话、终端敏感信息、报错堆栈、账号隐私信息或无关桌面内容。

45s-50s 的公开论文 PDF / ArXiv 页面不作为主展示画面。最终视频重点展示本地 Agent 页面和结果，不写成真实科研结论。
